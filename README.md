# Classificador de Dígitos Manuscritos - MNIST

## 🎯 Sobre o Projeto
Este projeto consiste no desenvolvimento de um modelo de Machine Learning capaz de classificar e reconhecer dígitos manuscritos (de 0 a 9) utilizando o conjunto de dados MNIST. O objetivo é automatizar o reconhecimento de imagens com alta precisão através do pré-processamento de dados e aplicação de algoritmos de aprendizado de máquina.

## 🛠️ Tecnologias e Técnicas Utilizadas
- **Linguagem:** Python
- **Análise e Manipulação de Dados:** Pandas, NumPy
- **Visualização de Dados:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn (Pré-processamento, divisão de treino/teste, métricas de avaliação e algoritmos de classificação)
- **Visão Computacional:** OpenCV, Pillow (para tratamento preliminar de imagens)
