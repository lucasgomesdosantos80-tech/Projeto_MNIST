# Projeto MNIST - Classificação de Dígitos Manuscritos

Este repositório contém o desenvolvimento e a análise do modelo de Machine Learning para classificação de dígitos manuscritos utilizando o dataset MNIST.

## 📌 Conteúdo
- `Projeto_MNIST.ipynb`: Notebook com a análise de dados, pré-processamento e treinamento do modelo.
- `requirements.txt`: Lista de dependências e bibliotecas necessárias para executar o projeto.

## 🛠️ Tecnologias Utilizadas
- Python
- Pandas / NumPy
- Matplotlib / Seaborn
- Scikit-Learn
